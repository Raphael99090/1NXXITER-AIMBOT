# Aimbot Documentation

## Overview
This documentation serves as a comprehensive guide for the Aimbot project. It covers installation, usage, and troubleshooting information.

## Features
- Automatic aiming at targets
- Customizable settings
- User-friendly interface

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Raphael99090/1NXXITER-AIMBOT.git
   ```
2. Navigate to the project directory:
   ```bash
   cd 1NXXITER-AIMBOT
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To use the aimbot, run the following command:
```bash
npm start
```

## Configuration
Edit the `config.json` file to customize settings such as target sensitivity, key bindings, etc.

## Troubleshooting
1. **Aimbot not aiming correctly**:
   - Ensure that the game is running in windowed mode.
   - Check sensitivity settings in the config file.

2. **Installation issues**:
   - Verify you have Node.js installed.
   - Ensure all dependencies are installed correctly.
